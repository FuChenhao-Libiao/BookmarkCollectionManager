# 🎵 智能音乐生成器 - 项目思路文档

## 🎯 项目主题

**智能音乐生成器（AI Music Generator）**

一个基于 Meta MusicGen 预训练模型的 AI 音乐生成 Web 应用，用户输入文本描述（如"欢快的钢琴曲"）或选择风格参数，AI 自动生成对应音乐片段，支持在线播放、下载和历史管理。前后端分离架构，后端使用 Python FastAPI。

## 💡 为什么选择这个主题？

1. **AI 新方向** - 区别于已有的计算机视觉（人脸考勤）和强化学习（五子棋），探索生成式 AI 音频领域
2. **无需训练模型** - 使用 Meta 开源的 MusicGen 预训练模型，直接加载推理
3. **交互体验好** - 文本描述 → AI 生成音乐，效果直观有冲击力
4. **实用性强** - 可用于短视频配乐、游戏音效、创作灵感激发
5. **技术栈差异化** - 涉及音频处理、流式传输、波形可视化等新技术点

## 🏗️ 功能规划

### 核心功能（第一阶段）
- [ ] 文本描述生成音乐（输入 prompt → 输出音频）
- [ ] 预设风格快捷选择（欢快、悲伤、史诗、电子、古典等）
- [ ] 音乐时长控制（5秒 / 10秒 / 15秒 / 30秒）

### 进阶功能（第二阶段）
- [ ] 生成历史记录管理（查看、重新播放、删除）
- [ ] 音频波形可视化播放器
- [ ] 音乐参数微调（temperature、top_k、top_p）
- [ ] 批量生成（同一描述生成多个变体）

### 扩展功能（第三阶段）
- [ ] 旋律续写（上传一段音频，AI 续写后面的旋律）
- [ ] 音乐风格混合（如 "70% 古典 + 30% 电子"）
- [ ] 生成音乐的标签自动标注
- [ ] 收藏夹功能

## 🧠 核心技术方案

### 1. MusicGen 模型调用

```python
from transformers import AutoProcessor, MusicgenForConditionalGeneration

# 加载模型（首次下载约 3.3GB，之后从缓存读取）
processor = AutoProcessor.from_pretrained("facebook/musicgen-small")
model = MusicgenForConditionalGeneration.from_pretrained("facebook/musicgen-small")

# 文本生成音乐
inputs = processor(
    text=["happy upbeat electronic dance music"],
    padding=True,
    return_tensors="pt",
)
audio_values = model.generate(**inputs, max_new_tokens=256)

# audio_values 是音频张量，采样率 32000Hz
```

### 2. 模型规格选择

| 模型 | 参数量 | 显存需求 | 生成速度 | 推荐场景 |
|------|--------|---------|---------|---------|
| musicgen-small | 300M | ~2GB | 快 | ✅ 开发/演示（推荐） |
| musicgen-medium | 1.5B | ~6GB | 中等 | 有独显时使用 |
| musicgen-large | 3.3B | ~12GB | 慢 | 高质量需求 |

默认使用 `musicgen-small`，CPU 也能运行（约30-60秒生成10秒音频），有 GPU 则几秒完成。

### 3. 音频保存流程

```
用户输入文本描述
    ↓
FastAPI 接收请求
    ↓
MusicGen 模型推理生成音频张量
    ↓
scipy.io.wavfile.write() 保存为 WAV 文件
    ↓
存储记录到 SQLite（prompt、文件路径、时长、时间戳）
    ↓
返回音频文件 URL 给前端
    ↓
前端播放 / 提供下载
```

## 🚀 部署和运行

### 环境要求
- Python 3.10+
- 磁盘空间 ≥ 5GB（模型缓存）
- 内存 ≥ 8GB
- GPU 可选（有则显著加速，无则 CPU 运行）

### 快速启动
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动后端服务
python app.py
# 服务运行在 http://localhost:8000

# 3. 打开前端页面
# 直接浏览器打开 frontend/index.html
```

### 首次运行
首次启动时会自动下载 MusicGen 模型（约 2GB），需要稳定网络。下载完成后缓存到本地，后续启动无需重复下载。

---

## ⚠️ 注意事项

1. **模型下载**：首次需要从 HuggingFace 下载模型，国内可能需要设置镜像
   ```bash
   set HF_ENDPOINT=https://hf-mirror.com
   ```
2. **生成速度**：CPU 模式下生成 10 秒音乐约需 30-60 秒，GPU 模式约 3-5 秒
3. **磁盘管理**：生成的 WAV 文件较大（10秒约 640KB），需定期清理
4. **并发限制**：模型推理占用大量资源，同一时刻只处理一个生成请求
